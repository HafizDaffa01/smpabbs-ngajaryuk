Generated by `laravel/ui`. Standard login, register, password confirmation, email verification.

- Uses `RegistersUsers` trait
- Redirect: `/home`

- Redirect: `/home`

## AbsensiController

**File:** `app/Http/Controllers/AbsensiController.php`
**Middleware:** `auth`

### Methods

| Method | HTTP | Purpose |
|---|---|---|
| `index()` | GET | Attendance form page with teacher list |
| `store(Request)` | POST | Validates + stores attendance. Prevents duplicate same-day check-in. Saves base64 photo to `public/uploads/`. Sends WhatsApp notification via Fonnte API with today's schedule. |

### Store Flow
1. Validate: `nama`, `lokasi`, `foto`, optional `alamat`, `akurasi`
2. Check for existing attendance today by same user -> reject if duplicate
3. Decode base64 photo -> save to `public/uploads/{timestamp}_{user_id}.jpg`
4. Create `Absensi` record
5. Get today's schedule for the teacher from `Schedule` model
6. Format WhatsApp message with schedule info
7. Send via Fonnte API (`POST https://api.fonnte.com/send`)
